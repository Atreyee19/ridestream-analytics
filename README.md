# ridestream-analytics

End-to-end Azure data engineering project using PostgreSQL, ADF, ADLS Gen2, Databricks, Delta Lake, dbt Cloud and Apache Airflow.

## Disclaimer

RideStream Analytics is a fictional ride-booking platform created for educational and portfolio purposes. All project data is synthetically generated and does not contain real customer or company information.

## Cost and Environment Note

This project is implemented in a cost-controlled Azure learning environment.

Small development compute and controlled event volumes are used to limit cloud costs. All chargeable compute, SQL warehouses, streaming jobs, simulators and triggers are stopped when not actively being tested.

The architecture and processing logic are designed to demonstrate production data-engineering patterns, but the portfolio environment is intentionally smaller than a production deployment.
